# AIHot 项目结构与代码阅读指南

本项目的 Java 后端位于 `backend`，Vue 前端位于 `frontend`；启动和配置参照 [配置与启动指南](配置与启动指南.md)。

## 目录职责

```text
aihot/
├── backend/                     Java 后端
│   ├── pom.xml                  后端 Maven 配置
│   └── src/
│       ├── main/java/cn/aihot/  应用入口及后端代码
│       │   ├── controller/      HTTP 请求和参数校验
│       │   ├── service/         检索、采集、AI 分析和邮件业务
│       │   ├── repository/      通过 JDBC 访问数据库
│       │   ├── model/           热点、分析结果等数据对象
│       │   ├── config/          配置、WebSocket 和旧数据导入
│       │   ├── security/        访问控制
│       │   └── util/            通用文本与 URL 处理
│       ├── main/resources/      Spring 配置和数据库初始化脚本
│       └── test/                后端测试
├── frontend/src/                Vue 前端
│   ├── App.vue                  整体框架、导航和公共弹窗
│   ├── views/                   检索、热点库、监控、通知、来源页面
│   ├── components/              热点卡片和 AI 设置弹窗
│   ├── composables/             页面共享状态与交互逻辑
│   ├── api/                     统一请求封装与显示常量
│   ├── assets/                  页面样式
│   ├── types.ts                 前端数据类型
│   ├── icons.ts                 本地图标组件
│   └── main.ts                  前端入口
├── project/                     项目辅助文件
│   ├── docs/                    使用与项目文档
│   ├── scripts/                 配置、构建及启动脚本
│   ├── sql/                     数据库相关脚本
│   ├── deploy/                  服务器部署配置示例
│   └── logs/                    以前的运行日志
└── .env                         本地配置（不要上传或分享）
```

后端的数据对象目前集中在 `model/Models.java`，请求参数对象放在 `ApiController` 中。项目没有实际使用的 Agent、工具调用或会话记忆模块，也没有采用 Vue Router 或 Pinia，因此没有为了凑目录而创建对应目录。

## 一次热点检索怎么读

1. `frontend/src/views/DiscoverView.vue`：输入关键词、选择来源，点击“开始检索”。
2. `frontend/src/composables/useWorkspace.ts` 的 `runSearch`：检查输入和来源，发起 `/search` 请求。
3. `frontend/src/api/index.ts`：为地址加上 `/api`，处理令牌、超时与错误。
4. `backend/src/main/java/cn/aihot/controller/ApiController.java` 的 `search`：校验参数和来源，调用业务服务。
5. `backend/src/main/java/cn/aihot/service/SearchService.java` 的 `search`、`execute`：组织采集、去重、分析、缓存、过滤和保存。
6. `SourceService` 负责采集，`AiService` 负责分析或规则降级；`repository/HotspotRepository.java` 负责查询与保存。
7. 服务通过 `RealtimeConfig` 推送任务进度；前端 `useWorkspace.ts` 中的 `connect` 接收消息，页面展示结果。

建议先顺着这条链路看整体，再分别看监控、通知和访问控制。数据库操作使用 Spring JDBC，并不是 JPA。
